# Periodic Report Template

This repository is a template repository used to create a new repository for tracking the progress of a project over time. 



## Purpose

This template helps students and supervisors:

- keep periodic reporting consistent
- review progress through the GitHub interface for supervisors
- maintain a clean timeline of project updates


## Use Instructions 

### The student workflow
For students, the workflow is mostly about **creating and maintaining the repository**. In plain terms: once the student has set up the repository properly, they add weekly reports as the project progresses, and push those updates to GitHub so the supervisor can review them.

The idea is that students manage the technical setup day to day. They create the repository, add weekly updates, and push those updates to GitHub. The supervisor will then review those updates and provide feedback. 

Instructions for students are detailed in the `student-detailed-TODO.html` file, to be downloaded and viewed in a web browser. Please **follow those instructions carefully** to ensure proper setup and use of the repository you have to create and maintain.

### The supervisor workflow
For supervisors, the workflow is mostly about **weekly review and feedback**. In plain terms: once the student has set up the repository properly and starts adding weekly reports, the supervisor checks those reports on GitHub, gives comments or guidance, and follows the student’s progress over time.

The idea is that supervisors do not manage the technical setup day to day. They wait until the repository is ready, then review the weekly updates, give feedback on what the student has done and what should happen next, and help steer the project if the student gets stuck. 

Instructions for supervisors are detailed in the `supervisor-quick-guide.md` file, that is easy to view in the GitHub interface.
