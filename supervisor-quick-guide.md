# Supervisor Quick Guide

## 🎯 Your Role
- **Review** students' weekly reports within 24 hours.
- **Provide feedback** on their progress, challenges, and plans.

---
## **Prerequisites**
- Ensure you have a **GitHub account**.
  > :green_circle: If you do not have a GitHub account yet, create one. Ask your favorite LLM for suggestions on **how to choose a username** and use your **university email address** for the primary email (you can easily change the primary email later, but changing the username later can be cumbersome).

  > :green_circle: If you already have a GitHub account with a personal email, you should add the university email as a secondary email in your GitHub account settings and *set it as the primary email for this repository*. This way, you can keep your personal and professional work separate while still using the same account. :warning: **The common mistake is to create a new GitHub account with the university email**, as *GitHub does not allow multiple accounts with the same email*. 

---

## 💬 How to Provide Feedback

### A. Initial Setup (one-time): Accept the GitHub Invitation
- You received an **email invitation from GitHub** to collaborate on the student's repository.
- Click the **"View Invitation"** button in the email to accept the invitation.

### B. Each reporting period: provide feedback on the weekly report

#### 1. Open the Email from your student
- Locate the email with subject **Weekly Report for Week XX** in your inbox
- Click the link in the email to open your web browser and navigate to the repository.
  - :warning: To access the repository, you will have to log into your GitHub account (the one linked to your university email).

#### 2. Navigate to the Weekly Report
- In the repository, find the **`week-XX.md`** file for the current week (e.g., `week-01.md`).
- Click on the file to open it in the GitHub interface.

#### 3. Edit the File
- Click the **pencil (✏️) icon** in the top-right corner of the file to open the GitHub editor.

#### 4. Add Your Feedback
- Read through the student's report.
- Scroll down to the **`💬 Supervisor Feedback`** section.
- Replace the placeholder text with your feedback.

#### 5. Save Your Changes
- Click the green button **Commit changes** (look top right) and: 
  - Add a **commit message** (e.g., `Add feedback for week-01`).
  - Leave the optional description blank (you wrote your feedback in file, no need to repeat here).
  - Keep the default option selected: "Commit directly to the main branch".
  - Click **Commit changes** to save your feedback.

---
That’s it! The student can now read the feedback you’ve added to their report.
